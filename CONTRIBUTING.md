# Contributing

Thanks for wanting to improve this project.

## How to contribute
1. Fork the repository.
2. Create a branch for your change.
3. Make your edits (scripts, instructions, or both).
4. Open a pull request with a short description of what you changed and why.

## Guidelines
- Keep instructions beginner-friendly. Prefer numbered steps and exact copy-paste commands.
- Test any script changes on the platform they target before submitting.
- Do not include real bot tokens, chat IDs, or other secrets in pull requests.
- Small, focused changes are easier to review than large rewrites.

## Questions
Open an issue if you have a suggestion or run into a problem with the instructions.
